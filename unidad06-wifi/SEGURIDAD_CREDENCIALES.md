# Credenciales Wi‑Fi

Los ejemplos del repositorio utilizan:
```text
TU_RED
TU_CLAVE
```

## No hagas commit de
- contraseña Wi‑Fi;
- tokens;
- claves API;
- certificados privados.

## Si publicaste una credencial
Eliminarla del archivo actual no la vuelve secreta automáticamente: puede permanecer en historial o copias. **Rótala** en el servicio correspondiente.

## Reto
Separa configuración sensible de un sketch público y documenta cómo debe completarla cada usuario localmente.
