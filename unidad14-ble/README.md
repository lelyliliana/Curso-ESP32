# Unidad 14 — Bluetooth y BLE

## Objetivo
Comprender comunicación inalámbrica de corto alcance.

La disponibilidad de Bluetooth clásico/BLE depende de la familia ESP32.

## BLE
Conceptos:
- peripheral/central;
- servicio;
- característica;
- lectura;
- escritura;
- notificación.

## Diseño
BLE puede ser útil para configuración local, sensores cercanos o interacción con móvil.

## Reto
Diseña un servicio BLE conceptual para exponer una lectura y recibir un parámetro de configuración.
