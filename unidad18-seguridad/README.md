# Unidad 18 — Credenciales y seguridad básica

## Objetivo
Evitar prácticas inseguras frecuentes en prototipos IoT.

## Credenciales
- no publicar SSID/contraseñas;
- no incluir tokens reales en Git;
- separar secretos del código versionado;
- rotar una credencial expuesta.

## Transporte
Prefiere protocolos cifrados cuando el escenario lo requiera y valida certificados correctamente.

## Superficie de ataque
Cada servidor, puerto o servicio expuesto añade riesgo.

## Validación
Valida comandos antes de controlar hardware.

## Actualizaciones
La capacidad de corregir software forma parte de la seguridad.

## Reto
Haz un modelo básico de amenazas de un nodo IoT: activo, amenaza, impacto y mitigación.
