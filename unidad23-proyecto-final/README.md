# Unidad 23 — Proyecto final IoT

## Propósito
Diseñar un sistema conectado completo y justificar sus decisiones.

## Requisitos
- problema claro;
- arquitectura de extremo a extremo;
- placa ESP32 identificada;
- sensores/actuadores documentados;
- alimentación;
- conectividad;
- protocolo;
- formato de mensajes;
- manejo de fallos;
- seguridad básica;
- estrategia de actualización;
- pruebas;
- README reproducible.

## Escenarios sugeridos
- monitoreo ambiental;
- agricultura a baja tensión;
- dispositivo doméstico local;
- estación de telemetría;
- robot conectado;
- sistema de alertas;
- nodo de ciudad inteligente a escala.

## Evaluación técnica
Explica:
1. por qué ESP32;
2. por qué Wi‑Fi/BLE;
3. por qué HTTP/MQTT;
4. qué ocurre sin red;
5. cómo proteges credenciales;
6. cómo actualizas;
7. cómo alimentas;
8. qué limitaciones permanecen.

## Cierre
> IoT no consiste en añadir Wi‑Fi a un circuito. Consiste en diseñar un sistema distribuido que siga teniendo sentido cuando la red, el sensor o el servicio fallen.
