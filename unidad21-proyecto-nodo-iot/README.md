# Unidad 21 — Proyecto: nodo IoT ambiental

## Objetivo
Construir un nodo que mida, publique y sobreviva a fallos temporales de red.

## Requisitos
- sensor ambiental compatible;
- identificación del nodo;
- Wi‑Fi con reconexión;
- telemetría MQTT o HTTP;
- JSON documentado;
- estado de error;
- temporización no bloqueante;
- credenciales fuera del repositorio;
- documentación.

## Pruebas
- red disponible;
- red ausente;
- servidor/broker ausente;
- lectura inválida;
- reinicio;
- recuperación.

## Extensión
Almacenamiento temporal y sincronización posterior.
