# Unidad 04 — Sensores, I2C y SPI

## Objetivo
Integrar periféricos reutilizando buses y comprobando compatibilidad eléctrica.

## Proceso
1. identifica sensor;
2. tensión y niveles;
3. interfaz;
4. dirección I2C si aplica;
5. biblioteca;
6. ejemplo mínimo;
7. integración.

## I2C
Permite varios dispositivos direccionados sobre un bus compartido.

## SPI
Utiliza más líneas y selección de dispositivo; puede ofrecer mayor velocidad.

## Reto
Escanea el bus I2C y documenta los dispositivos detectados antes de utilizar sus bibliotecas.
