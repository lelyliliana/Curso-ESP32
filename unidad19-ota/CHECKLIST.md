# Checklist OTA

Antes de actualizar:
- [ ] versión nueva válida;
- [ ] origen autorizado;
- [ ] integridad/autenticidad verificable;
- [ ] energía suficiente;
- [ ] espacio/partición;
- [ ] estrategia de recuperación.

Después:
- [ ] reinicio correcto;
- [ ] versión reportada;
- [ ] sensores/periféricos comprobados;
- [ ] conectividad;
- [ ] rollback/recuperación si falla la validación.

## Reto
Diseña una máquina de estados para actualización OTA.
