# Unidad 00 — Preparación, seguridad y placa

## Objetivo
Identificar la placa exacta y preparar el entorno sin asumir un pinout universal.

## Antes de empezar
- identifica familia, módulo y placa;
- localiza documentación oficial/fabricante;
- confirma USB/serial requerido;
- revisa pinout;
- confirma alimentación;
- recuerda que GPIO trabaja normalmente a 3.3 V.

## Entorno
Puedes utilizar Arduino IDE con el soporte ESP32 correspondiente. Selecciona placa y puerto correctos y prueba compilación/carga.

## Regla de credenciales
Nunca escribas contraseñas reales en ejemplos que publicarás. Utiliza archivos ignorados, variables de entorno en flujos compatibles o placeholders.

## Reto
Crea una ficha técnica de tu placa con modelo, alimentación, GPIO disponibles, buses y restricciones relevantes.
